# Archive

This directory preserves milestone-era artifacts that are not part of the final reproducible workflow.

- `milestones/` contains the Milestone 2 project plan, the Milestone 3 status report, and the exploratory notebook that informed the earlier stages of the project.
- `legacy_outputs/` contains pre-MS4 derived CSV files that were replaced by the final Snakemake workflow outputs.

These files are kept for provenance only. The final submission should be reproduced from `Snakefile`, `run_all.sh`, and the scripts in `scripts/`.
